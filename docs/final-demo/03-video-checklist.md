# SRE Copilot - Video Recording Checklist

## Pre-Recording Preparation

### Environment Setup
- [ ] Close unnecessary applications
- [ ] Clean desktop background
- [ ] Disable notifications
- [ ] Check disk space (min 5GB)

### Terminal Preparation
- [ ] Open fresh terminal
- [ ] Set readable font size (14pt+)
- [ ] Clear terminal scrollback
- [ ] Navigate to project directory
- [ ] Test demo command: `python demo_end_to_end.py`
- [ ] Verify all scenarios pass

### Audio Setup
- [ ] Test microphone levels
- [ ] Record 10-second test clip
- [ ] Eliminate background noise

### Visual Preparation
- [ ] Clean monitor screen
- [ ] Set resolution to 1920x1080
- [ ] Prepare architecture diagram
- [ ] Test screen recording software

---

## Recording Equipment

### Hardware
- [ ] Computer with sufficient CPU/RAM
- [ ] External microphone (preferred)
- [ ] Backup power source

### Software
- [ ] Screen recording software (OBS/Camtasia)
- [ ] Video editing software (optional)

### Recording Settings
- [ ] Resolution: 1920x1080 minimum
- [ ] Frame rate: 30fps minimum
- [ ] Format: MP4 (H.264)
- [ ] Audio: AAC, 48kHz

---

## Content Preparation

### Documents Ready
- [ ] Demo script accessible
- [ ] Project overview document
- [ ] Architecture diagram
- [ ] Key talking points

### Code Ready
- [ ] All demo scripts tested
- [ ] Scenarios validated:
  - [ ] APPROVE scenario
  - [ ] REJECT scenario
  - [ ] TIMEOUT scenario
  - [ ] SAFETY_INVARIANT scenario
- [ ] No errors or exceptions

### Backup Materials
- [ ] Screenshots of key output
- [ ] Slide deck with key points
- [ ] Architecture diagram

---

## Recording Process

### Start Recording
- [ ] Start screen recording software
- [ ] Begin recording
- [ ] Wait 3 seconds before narration

### During Recording
- [ ] Follow demo script segments
- [ ] Speak clearly
- [ ] Stay within 2-3 minute target

### Key Segments
- [ ] Introduction (15s)
- [ ] Problem & Solution (20s)
- [ ] Architecture (30s)
- [ ] Spec-Driven Development (20s)
- [ ] Steering & Hooks (20s)
- [ ] Property-Based Testing (20s)
- [ ] Kiro Power & MCP (20s)
- [ ] Live Demo (30s)
- [ ] Safety Invariant (20s)
- [ ] Security Validation (15s)
- [ ] Conclusion (10s)

### End Recording
- [ ] Wait 3 seconds after final word
- [ ] Stop recording
- [ ] Verify file saved

---

### Video Quality

- [ ] Check text is legible

### Audio Quality
- [ ] Listen to entire recording

- [ ] No background noise

### Content
- [ ] All segments covered
- [ ] Security boundaries highlighted

### Timing
- [ ] Duration: 2-3 minutes
- [ ] Appropriate pace
